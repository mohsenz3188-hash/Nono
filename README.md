# MOHSEN - شبیه‌ساز دسکتاپی LOGO! Soft Comfort برای اندروید

- **محیط دسکتاپی کامل:** نوار منو (File, Edit, View, Tools)، نوار ابزار آیکونی، درخت دستورات سمت چپ (Co / GF / SF) و صفحه کاملاً شطرنجی سفید.
- **شکل واقعی بلوک‌ها:** بلوک‌های زرد ورودی، سبز خروجی، گیت‌های استاندارد IEC و بلوک‌های SF با علائم گرافیکی.
- **تبدیل خودکار FBD به نردبانی (LAD)** + **جدول ارزشی خودکار** + **اسیلوسکوپ** + **تمامی مدارهای کتاب ۲۱۲۲۶۶**.
